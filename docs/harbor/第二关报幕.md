# 第二章｜黑箱堆场：没有灯的路

### 01 / 08 — 门的另一边

你终于穿过了五号泊位的维护门。

身后的枪声渐渐远去。那些本应保护幸存者的机械守卫，竟然毫不犹豫地向你开火。

你不知道自己究竟做错了什么。

对讲机里反复出现的那句话仍在耳边回响：

“未经授权的生命目标。”

可你明明只是想活着离开这里。

### 02 / 08 — 没有回应

你再次尝试联系撤离指挥中心。

“这里是五号泊位维修人员。我遭到了自动安保单位攻击……有没有人能够听到？”

无线电里只有断断续续的杂音。

几秒钟后，一个机械化的声音重复道：

“当前区域通讯服务不可用。”

随后，信号彻底中断。

这一次，没有人会来护送你了。

### 03 / 08 — 黑箱堆场

眼前是五号泊位与六号泊位之间的集装箱转运区。

数百个货柜层层堆叠，狭窄的货道在黑暗中不断延伸。有些集装箱已经倾斜，有些箱门半开，原本熟悉的运输路线早已难以辨认。

港区应急电力没有延伸到这里。

头顶的照明灯全部熄灭，只有雨水敲击钢板的声音，在集装箱之间久久回荡。

你打开手电，继续向前。

### 04 / 08 — 铁皮后面的声音

起初，你以为自己听见的是风。

一阵缓慢的摩擦声，从不远处的货柜后面传来。

紧接着，是拖沓的脚步声。

你停下脚步。

声音似乎也变得迟疑起来。

手电光束扫过空荡荡的货道，只照见锈蚀的箱门和地上的积水。

但你知道，那里有东西。

### 05 / 08 — 没有完成的撤离

灾变爆发后，大量人员曾试图从这片堆场撤往六号泊位。

有人遗弃了工具，有人在货柜之间寻找藏身之处，也有人试着利用维修通道绕开拥堵的主路。

后来，撤离行动中断了。

如今，仍留在这里的那些身影，未必还记得自己曾经是谁。

你必须小心。

在这样的地方，开枪不一定是最安全的选择。

### 06 / 08 — 最后的避难处

你想起港区曾在货物转运通道中设置过几处应急维修室。

那些地方原本用于设备故障时的临时避险，配有独立的应急照明和少量保障物资。

如果设施没有被彻底破坏，它们或许仍能提供片刻的安全。

但你不知道它们如今是否还完整。

更不知道，在找到下一间维修室之前，自己还会遇到什么。

### 07 / 08 — 六号泊位

从这片堆场的另一端穿出去，就是六号泊位。

那里曾经是港区的主要装卸和维修区域，拥有独立的值班设施与通讯设备。

或许还有幸存者。

或许有人知道那些机械守卫为什么突然向你开火。

远处的黑暗里，似乎有一束微弱的灯光。

你决定继续向那里前进。

### 08 / 08 — 没有灯的路

雨越来越大。

前方的货道在集装箱之间不断分岔，手电的光只能照亮眼前很短的一段距离。

某处突然传来一声沉闷的撞击。

然后，是一阵急促而不自然的喘息。

你握紧了手枪。

这条路上，没有人会来救你。

你唯一能做的，就是穿过黑暗。
