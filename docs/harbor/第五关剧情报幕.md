# 《末港：今夜离港》
## CHAPTER 05｜七号泊位：今夜离港

### 01 / 08 — 最后一道门

身后的重型安全门缓缓升起。

你穿过了第七区控制中心，终于进入七号泊位。

枪声仍在身后回荡，清场人员的无线电也没有停止。

但你已经顾不上那些了。

从五号泊位醒来，到穿过黑箱堆场，再到六号泊位和封锁控制中心，你几乎已经忘记自己究竟走了多远。

现在，最后一道门终于在你身后。

### 02 / 08 — 七号泊位

暴雨仍然笼罩着整片港区。

高耸的龙门吊矗立在黑暗中，废弃的货车和集装箱散落在道路两侧。

远处的海面上，只有断断续续的航标灯还在闪烁。

这里曾经是紫金港最繁忙的装卸区域之一。

如今，偌大的码头已经没有了正常作业的声音。

你沿着港区道路向前张望。

终于，在泊位尽头的黑暗里，看见了一艘船。

### 03 / 08 — 船还在

那是一艘港务工作艇。

虽然船身布满雨水，甲板上的灯也已经熄灭，但它仍然停靠在原来的泊位上。

你认识这艘船。

撤离行动开始以前，你曾参与过它的电力和燃油设备维护。

只要发动机还能工作，它就有可能沿着近岸航道离开封锁区。

你终于找到了自己一直寻找的东西。

但很快，你发现事情没有那么简单。

### 04 / 08 — 无法启动

工作艇的动力系统仍然处于锁定状态。

码头燃油管路没有供压，仓库控制系统也已经离线。

没有燃油，没有电力，没有解除封锁的权限。

即使船就在眼前，你也无法让它离开。

你望向港区中央。

那里还有一套应急配电装置。

如果设备没有彻底损坏，或许能够重新接通七号泊位的供电。

这是你最熟悉的工作。

也是你最后能做的尝试。

### 05 / 08 — 沉默的仓库

港区仓库的大门仍然紧闭。

根据你记得的维护流程，里面保存着燃油系统和工作艇泊位封锁的控制机关。

但仓库使用的是独立的安全联锁。

即使恢复供电，也需要等待系统完成自检，才能重新开启大门。

你不知道里面的设备是否还能够使用。

更不知道那些控制机关是否已经被清场部队破坏。

但如果它们仍然完好，你就有机会启动工作艇。

### 06 / 08 — 没有救援

一阵熟悉的广播从远处传来。

“这里是紫金港七号泊位……”

“请所有待撤离人员前往指定登船区域……”

“最后一班船即将离港……”

你停下脚步。

这些话，你已经听了整整一夜。

现在，你终于知道了它们背后的真相。

广播没有在引导幸存者撤离。

它只是把仍然活着的人，引向清除系统能够找到的地方。

从一开始，就没有人准备来接你们。

### 07 / 08 — 最后的围剿

远处忽然响起一阵机械运转声。

紧接着，是杂乱的脚步、急促的无线电，还有几声无法辨认的嘶吼。

感染者仍然在港区游荡。

清场部队也没有放弃追踪。

那些曾经负责维持秩序的机械守卫，仍在执行深潮科技下达的命令。

你看着不远处的应急电力装置。

一旦恢复供电，港区的系统就会重新启动。

那些东西也可能发现你的位置。

但你已经没有别的选择。

### 08 / 08 — 今夜离港

海风裹挟着雨水，猛烈地拍打着码头。

工作艇静静停靠在远处。

只差最后几道控制程序。

只差足够让发动机启动的燃油。

你已经不再期待救援，也不再相信任何撤离广播。

从这里离开，只能靠你自己。

你检查弹药，握紧武器。

然后，朝着港区中央的应急配电装置走去。

今晚，你一定要离开这里。
