# 《末港：今夜离港》
## CHAPTER 04｜封锁线：第七区控制中心

### 01 / 08 — 离开六号泊位

你离开了六号泊位的维修车间。

许工仍然留在那里，守着那间勉强安全的小屋。

临走前，他将一份维修主管的通行凭据交给了你。

那或许是你进入七号泊位的唯一机会。

而他最后提到的那个编号，始终萦绕在你的脑海中。

P-07。

### 02 / 08 — 不只是故障

五号泊位的机械守卫向你开火。

六号泊位的清场人员，也试图将你杀死。

他们使用不同的武器，执行不同的任务，却都将你视为需要清除的目标。

许工说，安保系统的目标识别名单曾经被远程改写。

如果他说的是真的，那么那些袭击或许从来都不是意外。

你必须找到记录。

### 03 / 08 — 第七封锁区

穿过六号泊位的连接通道，你进入了第七区控制廊道。

这里曾经是连接货运码头与中央安保设施的重要通路。

高大的隔离围栏沿道路延伸，集装箱被横七竖八地堆放在路边。

一辆废弃的港务车辆挡住了部分道路。

远处的工业照明仍在闪烁。

但你看不见任何正在值班的人。

### 04 / 08 — 被遗弃的防线

地面上散落着弹壳、破损的警戒标识和废弃的维修工具。

有些集装箱明显被仓促地挪动过，似乎有人试图利用它们封锁道路。

可这里没有守卫。

你突然意识到，一件事情很不对劲。

那些曾经负责封锁港区的人，究竟去了哪里？

### 05 / 08 — 熟悉的脚步声

一道低沉的撞击声从前方传来。

随后，是拖沓的脚步和断断续续的喘息。

你立即停下。

手电光扫过货柜之间狭窄的缝隙。

一个穿着港务工作服的身影，正缓慢地从黑暗中走出。

你认出了那种不自然的动作。

黑箱堆场里的东西，已经蔓延到了这里。

### 06 / 08 — 最后的控制中心

沿着封锁道路继续向前，便是通往七号泊位的最后一道安全门。

门旁保留着独立的控制终端和安保服务器。

许工告诉过你，港区的异常安保指令可能仍然保存在那里。

只要能够进入系统，你或许就能查明那些机器人和清场人员为什么要追杀幸存者。

但在此之前，你必须先穿过这段被感染者占据的通道。

### 07 / 08 — 最后一班船

远处的广播突然响起。

“这里是紫金港七号泊位……”

“请所有待撤离人员前往指定登船区域……”

“最后一班船即将离港。”

你已经听过无数次这样的广播。

它仍然平静、清晰，仿佛港口里的撤离工作从未中断。

你想起许工的警告。

“别再相信护送广播。”

### 08 / 08 — 封锁线

雨水不断冲刷着脚下的道路。

前方的集装箱之间，还有感染者在缓慢移动。

再往前，就是第七区控制中心。

而控制中心的后面，是你寻找了整整一夜的七号泊位。

你不知道那里是否真的还有一艘能够离开的船。

也不知道自己是否能够打开最后一道安全门。

但你已经走到了这里。

你必须弄清 P-07 的真相。

然后，活着离开。
